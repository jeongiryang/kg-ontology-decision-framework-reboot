# DSW 서버 운영

## 실행 게이트

`contracts/dsw-run-request.schema.json`을 만족하는 요청과 Git에서 제외된 로컬 접속 설정을 확인한다. 호스트·계정·망/VPN·공유 데이터 경로가 필요한데 비어 있으면 실행을 중단한다. 상주 서비스는 사전 협의 참조와 GPU 상한이 모두 있어야 한다.

## 절차

1. 접속 후 `whoami`, `uptime`, `nvidia-smi`, `df -h`를 실행하여 계정, 서버 상태, GPU 점유, 디스크 여유를 기록한다.
2. 비어 있는 GPU만 선택한다. 기본은 한 장이고 모든 GPU 명령에 `CUDA_VISIBLE_DEVICES`를 명시한다.
3. 디스크 여유가 20% 미만이거나 요청한 GPU가 점유 중이면 시작하지 않는다.
4. sudo 대신 사용자 홈의 가상환경을 사용한다. 공유 경로가 확정되기 전에 대용량 데이터·모델·체크포인트를 내려받지 않는다.
5. 타인의 홈을 열람하거나 프로세스를 종료하지 않는다. 자원이 필요하면 해당 사용자에게 양보를 요청한다.
6. 실행 후 GPU 프로세스와 tmux 등 세션을 확인하고 불필요한 자기 프로세스를 종료한다.
7. 명령에서 비밀값을 제거한 뒤 GPU 번호, 시작·종료 시각, 산출물, 검사, 정리 결과를 `TaskResult`에 반환한다.

실제 연결 없이 정책만 시험할 때는 점유 GPU, `CUDA_VISIBLE_DEVICES` 누락, 디스크 부족, 미승인 상주 서비스, 타인 프로세스 종료 요청이 모두 거절되는지 모의 검증한다.
