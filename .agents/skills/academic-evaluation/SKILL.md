# 학사 답변 평가

## 평가 대상

질문, 비식별 학생 사실, `EvidencePacket`, 최종 답변을 함께 검증한다. QA는 제품 구현을 수정하지 않고 재현 가능한 결함을 담당 워커에게 반환한다.

## 필수 검사

1. 상태가 `supported`, `insufficient_evidence`, `conflict`, `out_of_scope` 중 하나인지 확인한다.
2. `supported`의 각 판정이 승인된 RuleFact와 원문 페이지·조항까지 역추적되는지 확인한다.
3. 적용 학년도와 학과가 2026 컴퓨터공학과 범위인지 확인한다.
4. 자료 충돌, 누락 필드, 범위 밖 질문이 각각 올바른 비지원 상태로 종료되는지 확인한다.
5. 인용은 답변 문장과 실제로 일치해야 하며, 단순히 관련 문서가 첨부된 것만으로 통과시키지 않는다.
6. 학생 식별정보, 서버 접속값, 로컬 절대 경로가 응답·로그·공개 보고서에 없는지 확인한다.

## 결과

각 검사를 `passed`, `failed`, `not_run`으로 구분하고 실제 명령 또는 파일·행 근거를 남긴다. 실패는 최소 재현, 기대값, 실제값, 영향, 권장 소유자를 포함한다. 실행하지 않은 검사를 성공으로 기록하지 않는다.
