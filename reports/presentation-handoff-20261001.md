## 23:24 KST - 마지막 누적 5회 수정과 독립 검증

마지막 제품 수정본을 동결했다. 명시적인 목적/속성 계획, 별칭·후속 질문, 전체 졸업요건 및 전필/전선 개수, 짧은 근거 참조 복원, 상세 접힘과 PDF 버튼을 보완했다. 생산자가 실행한 관련 171개 검사는 통과했지만 최종 독립 검증과 실제 모델 평가를 대신하지 않는다. 승인 29규칙·3출처·43과목과 기존 보류는 변경하지 않았다.

독립 QA의 기존 30개 목적별 검사는 통과했고, 새 원문 기반 경계 검사 6개는 실제 재현에 실패했다. 스크립트로 제어한 비신뢰 모델 출력을 실제 서비스 코어에 넣은 검사이며, Gemma가 동일 문장을 실제 생성했다고 주장하지 않는다.

1. 균형교양 영역별 최소 1과목을 3과목으로 바꾼 문장을 허용한다.
2. 같은 과목의 학점과 필수 이수를 함께 묻는데 학점을 누락한 채 지원됨으로 표시할 수 있다.
3. 전체 졸업요건과 특정 과목 학점을 함께 물을 때 과목명을 요건에서 찾았다는 이유로 학점을 누락할 수 있다.
4. 전필/전선 개수 요청에서 두 분류 도구가 있어도 숫자 9/34 없이 분류만 출력할 수 있다.
5. 심층상담 최소 1회와 매 학기 권장사항을 구분하지 않은 의무 문장을 허용한다.
6. 졸업작품 선행조건인 캡스톤 II PASS를 부정하는 문장이 별도 단서를 붙이면 검증을 통과할 수 있다.

전체 회귀는 처음 773개 중 3건, 새 경계 검사 추가 후 779개 중 9건 실패했다(실행 오류 0). 6건은 위 제품 결함이다. 다른 3건은 예전 질문 예시/레거시 API를 기대하는 검사와 실행 중인 공개 시연의 고정 포트를 요구하는 테스트 환경 문제로 구분했다. 해당 테스트만 실제 의미 기반 API·독립 포트로 보정하고 다시 확인한다. 제품 결함을 숨기기 위해 검사를 생략하거나 성공 기준을 낮추지 않는다.

실제 Gemma 수정용 24사례/36발화는 실행 완료했고, 별도 16사례/30발화는 독립 판정 전 실제 실행 중이다. 성공/실패 수치는 원문 기준 QA 판정 후 정제 평가에 기록한다. 단순 학점·구분·편성 및 일부 후속 질문에서 실제 생성이 관찰됐지만 복합 질문의 누락·처리 실패·안전한 원문 대체도 관찰돼 자연스러운 완성품으로 단정하지 않는다.

최종 동결 서버를 새로 읽은 실제 브라우저에서 가상 PDF 3종을 다시 인식/비교했다. 초기 6행/15학점/부족115, 130학점 45행/부족0·논문 미이수, 재수강 7행/9학점/부족121이며, PDF577쪽/인쇄569쪽의 정확한 기초교양9 교차 위치에 빨간 밑줄이 표시됐다. 학생 성적표나 이수내역을 모델에 전송하지 않았다.

독립 리뷰와 QA는 필수 실패로 장부에 등록했다. 마지막 누적 5회 뒤 자동으로 여섯 번째 제품 수정을 시작하지 않는다. 남은 결함은 새 재개 범위에서 수정·재검증해야 한다. 추가 학사 규정 설명이 없어 생긴 결함이 아니며 사용자에게 같은 승인 질문을 되풀이하지 않는다. 공개 시연 서버는 기존 실행을 유지하고, 필수 실패가 있는 비공개 수정본을 공개 실행으로 교체하지 않았다.

## 21:55 KST - 실제 모델 시험과 독립 리뷰 체크포인트

같은 네 파일의 목적별 수정 4회를 동결하고 비공개 서버에서 실제 Gemma API를 네 번 호출했다. 과목 근거의 값·해시는 연결됐지만, 학점만 요청한 두 질문은 문장 검증에 실패해 전체 과목 행을 반환했다. 논문을 함께 언급한 졸업요건 요약은 논문만 처리했고, 전필/전선 개수 질문은 개수 대신 졸업요건 전체를 반환했다. 네 번 모두 검증된 자연어 생성은 실패했다. 이는 연결 유무나 실제 학사 근거 부족의 문제가 아니라 조회 목적·완전성·문장 처리 결함이다. 기존 관찰을 삭제하거나 성공으로 바꾸지 않았다.

비작성 부분의 독립 읽기 전용 리뷰는 필수 검사 실패로 등록했다. 목적 필드 누락, 논문을 포함한 전체 요약, 개수 질문의 목적 불일치, 필수 이수/영역 조건 검증 빈틈, 필터 범위를 설명한 개수 답변의 잘못된 거절, 정책에 과목명이 있다는 이유로 과목 속성을 처리했다고 보는 결함의 여섯 항목이다. 출처/해시/그래프 연결, 질문 안전 검사와 학생 기록의 모델 비전송, 기존 모델 호출·시간·크기 제한은 검토 범위에서 유지됐다. 정적 리뷰의 결함 추적과 실제 재현은 구분한다.

구현 담당이 실행한 관련 135개 검사는 통과했지만 독립 최종 통과의 근거가 아니다. 독립 QA의 질문 40사례/66발화에 대한 원문 기반 기대값과 비공개 판정기를 동결했고, 알려진 테스트 계약 오기를 먼저 교정한 뒤 새 테스트를 실행하도록 배정했다. 실행하지 않은 사례를 통과로 표시하지 않는다. 다음 제품 수정은 기존 세 번과 4회를 보존한 마지막 누적 5회이며, 필수 실패가 남으면 완료로 보고하지 않는다.

관련 새 실행: `20261001-purpose-dialogue-repair4-resume`(작성 체크포인트), `20261001-purpose-backend-review4-v1`(필수 리뷰 실패), `20261001-purpose-live-design-v1`(기대값/판정기 설계 완료), `20261001-purpose-qa-execution4-v1`(독립 실행 중). 실제 원시 응답은 Git 제외 로컬 평가 기록에 있으며 공개 서버와 나루 서비스는 교체하거나 수정하지 않았다.
