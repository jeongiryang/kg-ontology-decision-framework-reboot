# 참고자료 유형 기반 합성 회귀

교수님 챗봇의 개발원 테스트 JSON 3개는 질문·답변 원문이 없는 평가 요약이다. 파일에 기록된 PASS나 상태를 우리 챗봇의 결과로 사용하지 않았다. 개인정보·원본 JSON은 공개하지 않는다.

새 합성 15건은 `evaluations/academic-reference-patterns.json`에 작성했다. 자동평가 결과는 지원 3건, 근거 부족 9건, 범위 밖 3건이다. 지원 사례의 승인 해시·SourceEntry·실제 locator, 117→130학점 부족분13, API·CLI·코어 동일 응답을 검증한다. PCCP·캡스톤·공모전 보류 질문은 규칙·인용을 노출하지 않는다.

이는 제한된 현재 동작의 회귀 확인이지 자연어 정확도·교육적 효과·사용자 만족도 결과가 아니다. 자유형 학점 숫자, 자연스러운 복수 질문과 문맥 없는 후속 질문은 현재 제한으로 남아 있다. 실제 사람 UAT는 **not_run**이며 [진행 절차](../../docs/operations/human-uat.md)에 따라 별도로 수행한다.
