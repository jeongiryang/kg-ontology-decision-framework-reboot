# 2026학번 웹 프로토타입 사용성 파일럿

학생이 실제로 물을 법한 비식별 한국어 질문 30개를 고정 시나리오로 구성했다. 실제 학생
대화 로그를 수집한 결과가 아니라, 승인된 규칙과 현재 보류 범위를 바탕으로 작성한 초기
사용성 검증 세트다.

| 결과 | 건수 | 검증 기준 |
|---|---:|---|
| `supported` | 22 | 승인된 RuleFact와 출처 locator가 모두 연결됨 |
| `insufficient_evidence` | 6 | 공모전·캡스톤·PCCP·졸업작품·개인 판정·포괄 판정을 근거 없이 거절 |
| `out_of_scope` | 2 | 2026학번 또는 컴퓨터공학과 범위를 벗어난 요청 거절 |

학점 부족분 질문 4개는 사용자가 입력한 비식별 학점 합계만 사용해 각각 10, 3, 4, 4학점의
부족분을 계산한다. 모든 비지원 응답은 적용 규칙과 인용이 비어 있어야 한다.

재현 명령:

```bash
python scripts/validation/validate_academic_usability.py --project .
```
