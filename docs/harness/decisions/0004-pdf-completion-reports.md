# ADR-0004: 중대 변경은 PDF 완료 보고서로도 제공한다

- 상태: 채택
- 날짜: 2026-09-17

## 맥락

사용자는 무엇이 반영·수정·추가되었고 어떤 검사를 했는지 GitHub 문서뿐 아니라 제출·공유 가능한 형태로 확인해야 한다. 모든 작은 수정에 PDF를 만들면 잡음과 검증 비용이 커지지만, 규칙·계약·보안·마일스톤 변경에는 고정된 보고물이 유용하다.

## 결정

모든 완료 작업은 Markdown과 구조화 JSON 보고서를 만든다. 제품 동작, 학사 규칙·온톨로지, API·스키마, DSW·모델 구성, 개인정보·보안 정책 또는 마일스톤 변경에는 동일한 `CompletionReport`에서 PDF도 생성한다. 모든 페이지를 이미지로 렌더링해 한글, 표 겹침, 잘림, 페이지 번호를 확인한다.

## 결과

사람용 보고서와 기계 검증 데이터가 같은 실행 ID와 Git SHA로 대응한다. PDF 생성과 시각 검증 비용이 추가되며, 오탈자나 영향 없는 서식 변경은 PDF 대상에서 제외된다. 생성 명령 성공만으로 PDF 품질 통과를 주장할 수 없다.

## 검토한 대안

- Markdown만 제공: 제출·공유 환경의 고정 레이아웃 요구를 충족하기 어려워 채택하지 않았다.
- 모든 작업에 PDF 생성: 사소한 변경의 비용과 저장소 잡음이 커 채택하지 않았다.
