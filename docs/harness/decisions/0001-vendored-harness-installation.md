# ADR-0001: 고정된 하네스 설치본을 저장소에 포함한다

- 상태: 채택
- 날짜: 2026-09-17

## 맥락

프로젝트는 `codex-harness`를 재현 가능하게 사용해야 한다. Windows Git 환경에서는 업스트림이 사용하는 심볼릭 링크가 일반 파일로 체크아웃되거나 권한 오류로 생성되지 않아 설치가 실패할 수 있다. 링크나 최신 브랜치에 의존하면 같은 커밋에서 같은 에이전트·스킬을 보장하기 어렵다.

## 결정

WSL에서 업스트림 커밋 `79b82281d305c89181fbb216499d5f1e962c14ed`를 체크아웃하고 설치기의 dry-run을 확인한 뒤 Windows 프로젝트 경로로 설치한다. 설치된 기본 역할과 `harness` 스킬은 프로젝트 저장소에 포함한다. 업스트림 SHA와 Apache-2.0 고지를 유지한다.

## 결과

클론 후 하네스 구조를 로컬에서 검토할 수 있고 업스트림 변경이 자동 유입되지 않는다. 반면 업스트림 보안·기능 변경은 [갱신 절차](../upstream.md)를 통해 명시적으로 병합해야 하며 프로젝트 맞춤 변경과의 차이를 관리해야 한다.

## 검토한 대안

- 서브모듈: 초기 설정과 오프라인 사용이 복잡해 채택하지 않았다.
- 실행 시 최신 업스트림 다운로드: 재현성과 공급망 고정이 약해 채택하지 않았다.
- Windows 일반 clone: 현재 심볼릭 링크 제약으로 설치 신뢰성이 낮아 채택하지 않았다.
