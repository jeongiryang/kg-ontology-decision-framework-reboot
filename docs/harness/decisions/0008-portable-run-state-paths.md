# ADR 0008: 실행 상태 경로를 POSIX 형식으로 정규화

- 상태: 채택
- 날짜: 2026-09-18

## 맥락

Windows에서 선행 작업 결과 경로를 `str(Path(...))`로 직렬화하면 역슬래시가 기록된다. 하네스의 안전한 프로젝트 경로 계약은 `/` 구분자만 허용하므로, 의존성이 있는 후속 작업을 시작할 때 자체 생성 경로가 거부되었다.

## 결정

실행 계획, 결과, 입력 스냅샷에 기록하는 모든 프로젝트 상대 경로는 `Path.as_posix()`로 직렬화한다. 절대 경로, 상위 경로 이동, 역슬래시는 계속 거부한다.

## 결과

- Windows와 Linux/WSL에서 같은 실행 상태 계약을 사용한다.
- 운영체제를 바꾸어 실행을 재개해도 의존성 결과 경로가 유효하다.
- 경로 안전성 검사는 완화하지 않는다.
