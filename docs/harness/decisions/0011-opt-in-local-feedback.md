# ADR 0011: 비지원 질문은 명시적 동의로만 로컬 저장한다

## 상태

승인됨

## 배경

근거 부족·충돌 질문을 수집해야 지원 범위를 개선할 수 있다. 그러나 일반 질문을
자동 저장하면 기존 비저장 약속과 개인정보 최소화 원칙을 훼손한다.

## 결정

- 일반 답변 요청은 계속 저장하지 않는다.
- 근거 부족·충돌 답변에만 피드백 UI를 표시하고 범위 밖 응답은 수집하지 않는다.
- 사용자가 개인정보 부재를 확인하고 저장 버튼을 누른 경우에만 수집한다.
- 질문, 응답 ID, 비지원 상태, 유형과 고정 범위만 `.local/academic-feedback/feedback.jsonl`에 저장한다.
- PII 패턴, 동의 누락과 `supported` 상태는 422로 거절한다.
- 저장 경로는 Git에서 제외하고 공개 보고서에 원문을 포함하지 않는다.

## 결과

보완 대상 질문을 재현 가능하게 모을 수 있지만 이는 공식 학사 근거나 승인 규칙이 아니다.
운영자가 검토한 뒤 출처 감사와 별도 검수 세션을 거쳐야만 답변 지식으로 승격할 수 있다.
