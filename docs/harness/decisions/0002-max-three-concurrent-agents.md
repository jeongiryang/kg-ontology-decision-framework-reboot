# ADR-0002: 동시 서브에이전트를 최대 3개로 제한한다

- 상태: 채택
- 날짜: 2026-09-17

## 맥락

병렬 실행은 독립 작업의 지연을 줄이지만 동일 파일 충돌, 오래된 입력, 통합 부담과 런타임 슬롯 경쟁을 만든다. 현재 프로젝트 설정은 세션당 최대 세 개의 동시 서브에이전트를 허용한다.

## 결정

첫 대기 자식의 실제 생성과 ID 반환을 확인한 뒤, 서로 독립적이고 쓰기 소유권이 겹치지 않는 작업만 최대 3개까지 실행한다. 실제 런타임 한도가 더 작으면 더 작은 값을 따른다. 읽기 전용 조사·리뷰는 병렬화할 수 있지만 의존 구현과 QA는 순서대로 실행한다.

## 결과

속도와 통합 안정성 사이의 경계를 명확히 한다. 역할 파일이 많아도 모두 동시에 실행하지 않는다. 슬롯이 남는다는 이유만으로 작업을 쪼개지 않으며, 에이전트 유휴·중단이 실제로 확인되기 전에는 슬롯 반환을 가정하지 않는다.

## 검토한 대안

- 무제한 팬아웃: 충돌과 검증 비용이 커 채택하지 않았다.
- 완전 순차 실행: 독립 조사와 문서 작업의 지연이 불필요하게 커 채택하지 않았다.
