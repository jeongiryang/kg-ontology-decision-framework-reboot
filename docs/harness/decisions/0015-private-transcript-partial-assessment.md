# ADR0015: 비식별 성적표 확인과 부분 졸업요건 비교

- 상태: 승인된 제품 범위의 구현 결정
- 일자: 2026-09-30
- 학사 규칙 신규 승인: 없음

## 결정

성적표 PDF를 메모리에서 로컬 인식한 뒤 사용자가 수정·확인한 과목만 결정론적 비교에 사용한다. 이름·학번·원문은 계약에 없고 모델에도 보내지 않는다. 기존 일반 질문 개인정보 차단은 유지하고 전용 extract/assess/chat 인터페이스를 둔다. 학생 기록은 SourceEntry가 아니라 확인된 계산 입력이다.

필수과목 정확 식별,0학점 이수,학점 상한,중복 제외,누락 내역·이수유형 경계를 적용한다. 승인된 학점·과목 비교마다 EvidencePacket을 연결하되 최종 졸업 인증은 하지 않는다. 심화 배분과 개인 예외,보류 운영 관계는 근거 확보 전까지 확인 필요다. 기본78전공/18잔여 프로필 적용을 명시적으로 확인하며 다전공자를 자동 포함하지 않는다.

## 이유와 영향

Gmail 실물은 다른 입학년도여서 인식 형식 확인에만 사용한다. 2026 가상 기록으로 범위 내 계산을 검증한다. PDF10MiB·10페이지,동시 OCR1건,명시 페이지 선택과 시간 제한은 개인정보 처리 범위를 줄인다. 공개 fixtures에는 실제 성적표를 복사하지 않는다.

Windows 한국어 OCR을 이용할 수 없는 환경은 직접 입력으로 진행한다. 과목 의미·영역·배분을 LLM이나 유사도로 추정하지 않는 대신 사용자가 확인할 부분을 화면에 표시한다. 개발원 직접 평가는 사용자의 결정으로 생략하되 자동·독립 QA는 유지한다.

독립 검증에서 발견한 동일 과목 식별·0학점 불일치·정확한 확인 boolean·후속 응답 순서·중첩 근거 계약 문제는 수정 후 새 실행에서 재검증한다. 학생 판정이 근거 부족이면 공통 계약의 빈 규칙·인용을 유지한다. 기준 설명은 별도 정책 packet으로 표시해 확정 학생 판정과 구별한다. PDF 전체는 종료 가능한 프로세스와 전체 시간 제한으로 격리한다.

다음 문단은 2026-09-30 당시 정책 기록이다. 고정 디스크 비율 차단 부분은 2026-10-01 [ADR0017](0017-remove-fixed-dsw-disk-threshold.md)로 대체되었으며 현재 실행 조건이 아니다. 나루 보호와 타인 프로세스 보호 등 나머지 경계는 유지한다.

DSW에서 나루GPU를 제외하는 것은 필수이나 충분 조건은 아니다. 현재 실제 사전점검의 디스크 게이트가 통과되지 않으면 모델을 시작하지 않고 미실행을 공개 보고한다. 파일 정리·타인 프로세스 변경·안전 기준 하향은 이 결정으로 허용되지 않는다.
