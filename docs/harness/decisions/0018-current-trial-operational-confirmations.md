# ADR0018 — 좁은 학과 확인 운영정책과 비PDF 인용

- 상태: 채택
- 결정일: 2026-10-01

## 배경

종료된 검수 세션의 권한으로 새 사용자 설명을 승인할 수 없다. 현행 시범 PCCP 점수,
미통과 처리와 졸업작품 선행조건은 교육과정 학점표에 없는 운영정책이다.
점수를 학점으로 취급하거나 확인 기록에 가짜 PDF 페이지를 붙이면 근거를 왜곡한다.

## 결정

새 세션의 명시적 범위 재확인으로 출처1건과 규칙3건만 승인한다.
별도 불변 확인 원문의 SHA-256, 정확한 질문·답변, 권한 사건, 검수대장과 입력/출력
승인 해시를 연결한다. 과거 원답변과 닫힌 세션은 그대로 보존한다.

RuleFact 2.1은 `operational_policy`의 세 엄격한 분기를 추가한다.
기존2.0 객체는 바이트를 바꾸지 않고 계속 검증하며, 새 타입은2.1·`policy_statement`·
`direct`로 제한한다. 하네스 색인은 현재 버전2.1을 가리키며 버전 열거형의
`x-current-version`도 대조한다.

전문을 일치시키는 좁은 일반정책 질문만 지원한다. 현행400점은 확인일 당시 시범 기준이며
미래의 기준·개인 PASS·졸업 판정으로 확대하지 않는다. 캡스톤 I 미통과 처리는 U이며
I의 수강 자체 금지가 아니다. 졸업작품 수강은 II PASS를 선행조건으로만 설명한다.
면제의 수강·학점 처리,600점 고정 기준과 정확한 제출 마감은 계속 별도 보류한다.

학과 확인은 비PDF 텍스트 인용으로 구분하고 PDF 미리보기 요청을 만들지 않는다.
원본 PDF가 있는 기존 규칙은 해시 연결된 빨간 밑줄 표시를 유지한다.
새 그래프는 별도 빈 로컬 개발 DB에 적재하며 기존 DB·타인 데이터는 지우지 않는다.

독립 리뷰에서 세 정책의 졸업논문 `supplement` 연결이 승인 범위를 넘는다는 결함을 발견했다. 독립 `base`/빈 대상 관계로 교정하고 [관계 교정 대장](../../../knowledge/relationship-corrections.json)에 이전·현재 해시를 연결한다. 닫힌 승인 패킷은 변경하지 않으며 이전 관계만 복원한 객체가 원승인 해시와 일치해야 한다. 학사 결정·검수 내용의 변경에는 사용할 수 없는 보수적 정정 경로다. 운영 타입은 `answer_policy` 필드 자체도 필수다.

## 결과

운영정책과 교육과정 학점을 혼용하지 않으며, LLM은 비식별 의도 제안만 수행한다.
정정은 새 세션과 버전 이력으로 처리한다. 원본 확인 기록 변경·승인/그래프 해시
불일치는 실패 폐쇄한다. 인증 비활성 localhost DB는 개발용이고 외부 공개용이 아니다.
