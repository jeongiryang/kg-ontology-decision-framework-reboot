# ADR0016: 해시와 원문 위치가 연결된 PDF 근거 표시

- 상태: 승인된 사용자 구현 요청 반영
- 날짜:2026-10-01

## 결정

원본 PDF를 바꾸거나 저장소에 복사하지 않고,승인된 규칙 ID로만 인용 페이지를 연다.
SourceEntry 해시와 현재 원본 바이트가 일치해야 한다. 인용문 또는 표의 행·연도·열·값이
유일하게 검증된 경우에만 빨간 밑줄을 그린다. 수기·병합·중복으로 위치를 확정할 수 없는
경우 `page_only`로 안내하며 임의의 정확한 위치를 만들지 않는다.

## 경계

위치 검증은 학사 규칙 승인과 별개다. 보류 규칙을 지원 상태로 승격하거나 개인 성적표를
학사 원본으로 등록하지 않는다. API의 출처 설정과 학생 자료는 Git에서 제외한다.
표시 이미지와 한 페이지 PDF 사본은 메모리에서 생성한다. 원본 변경을 요구하는 기능이 아니다.

LLM 준비 상태는 설정·읽기 전용 모델 목록 확인과 실제 추론을 분리한다. DSW 디스크
안전 게이트는 이 결정으로 완화되지 않으며,기존 모델 재사용 예외는 별도 명시적 확인이 필요하다.

## 결과와 검증

좌표를 잘못 표시하는 것보다 페이지 단위 근거를 정직하게 제공한다. 해시 변조,미승인 규칙,
인용 범위 밖 페이지,중복 텍스트,선택 변경 중 오래된 응답,표 행·열 대응을 검사한다.
사용자 안내는 [PDF 근거 보기](../../operations/pdf-evidence-viewer.md)를 기준으로 한다.
