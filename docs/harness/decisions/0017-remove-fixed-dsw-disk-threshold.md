# ADR0017: DSW 고정 디스크 여유 비율 차단 제거

- 상태: 채택
- 날짜: 2026-10-01
- 범위: 프로젝트 DSW 하네스 지침·설정·운영 문서

## 배경

기존 지침은 디스크 여유가 20% 미만이면 새 작업을 시작하지 않도록 했다. 사용자 요청으로 해당 조건을 영구 제거한다. 이 결정은 연구실 전체 관리 규정을 변경하거나 이번 GPU 실행을 자동 승인하는 것이 아니다.

## 결정

- 에이전트 지침·스킬에서 고정 디스크 비율 차단을 제거한다.
- 공개 설정 예제와 Git에서 제외되는 로컬 설정에서 `minimum_free_disk_percent`를 제거한다. 다른 비율이나 일회성 예외 승인으로 대체하지 않는다.
- `df -h`를 통한 상태 확인·기록과 실제 파일시스템 오류의 보고는 유지한다.
- 나루 GPU·프로세스를 보존하고 다른 빈 GPU 1장을 기본으로 선택한다. `CUDA_VISIBLE_DEVICES`는 항상 지정한다.
- 본인 계정·사용자 가상환경·타인 홈과 프로세스 보호·상주 서비스 사전 협의 및 GPU 상한·공용 경로 확인 전 대용량 다운로드 금지·학생정보 비전송은 유지한다.

## 영향과 검증

이 조건은 실행 프로그램이나 JSON Schema의 수치 검사로 구현되어 있지 않았다. 따라서 새 게이트 프로그램·계약 버전을 만들지 않고, 에이전트·스킬·설정을 동기화한다. 기존 GPU 장치 지정·상주 승인 계약의 거절 동작은 테스트한다.

과거 실행·보고서는 당시 정책과 실제 결과를 보존한다. 후속 서버 작업은 새 입력 패킷에서 현재 정책을 읽으며 예전 디스크 예외 승인을 요구하지 않는다. 정책 변경 자체는 GPU 추론·챗봇 연결 성공의 증거가 아니다.

관련 운영 기준: [DSW 서버 운영 계약](../dsw-operations.md).
