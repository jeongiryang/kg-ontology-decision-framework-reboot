# ADR0022 - 친절한 근거 안내와 휘발성 대화

- 날짜:2026-10-01
- 상태:채택
- 부분 확장:[ADR0019](0019-bounded-dialogue-transcript-and-supervision.md),
  [ADR0021](0021-verified-gemma-claim-generation.md)

## 결정

기능 연결 완료와 자연스러운 대화의 완성은 구분한다. 사용자가 친절한 존댓말, 같은 대화의
질문·성적표 기억, 새 대화 초기화와 시연10개를 넘는 질문 지원을 요청했다. 기존 단일 앱의
friendly 스타일과 완전한 질문 문법을 확장하며 상주 에이전트·새 DB·세션 서비스를 만들지 않는다.

판정·계산·인용은 기존 근거 코어가 맡는다. `conversational_answer`는 설명용 추가 필드이며
정책 답변의 `presentation_claim_ids`는 승인된 전체 적용 규칙 순서와 같아야 한다. 생성 문장은
수치·비교 방향·조건·예외를 보존하는 닫힌 한국어 표현만 허용한다. 기본3~5문장은 목표이며
완전한 설명을 생략할 수 있는 상한이 아니다. 원문 밖의 제도 취지나 원인도 만들어 넣지 않는다.

기존31의도 전체의 다양한 완전한 질문을 해석한다. 모르는 절차·범위·예외를 지운 뒤 알려진
부분만 `supported`로 만드는 방식은 금지한다. 모호하면 후보를 확인하며 보류된 학사 사실은
새 대화 기능 때문에 승인되지 않는다. 이전 질문도 현재 승인 규칙·사실로 다시 검증한다.

브라우저에만 최대6턴 표시, 마지막 명확한 정책 질문과 성적표 비교 질문, 확인한 성적표를
메모리로 둔다. 정책과 개인 비교의 API·근거 상태는 분리한다. 새 대화는 성적표·학점·확인 상태·
PDF 화면까지 지우며 요청 순서와 자료 세대로 늦은 성공·오류를 차단한다. 서버 세션이나
브라우저 영구 저장은 없다. 모델에 질문·대화·학생 사실을 전송하지 않는다.

먼저 모델 호출 없는 안내를 반환하고, 연결이 준비된 경우에만 원래 요청으로 선택적 Gemma
다듬기를 한 번 시도한다. 첫 판정·계산·근거와 자료 세대가 같을 때에만 표현을 갱신한다.
실패는 첫 안내를 없애지 않는다. 모델이 실제 작성한 검증 문장을 그대로 보여 주며, 규칙
기반 문장을 모델이 썼다고 표시하지 않는다. 나루 보호용 단일 추론·공개 최소60초 간격과
절대 기한·실패 대기를 유지한다. 브라우저 취소와 원격 추론 취소는 다른 사실이다.

## 검증

메인이 계약·화면을 통합하고 배타적 backend worker, 읽기 전용 reviewer와 테스트 전용 QA를
순서대로 운영한다. 전체 의도와 시연 외 표현, 복합 질문, 모호성, 문맥/단위, 학생 자료 수정,
빠른0추론 경로, 선택적 생성과 지연 결과, 기존 API 호환과 공개 정제 보고를 확인한다.
등록된 표현 평가와 별도로 선택한 질문 문법도 검사한다. 성적표 언급은 전용 개인 비교
경로의 제한된 일반 참조에만 허용하며 전역 개인정보 검사를 완화하지 않는다. 한 질문의
비교 결과만 공유하여 중복 계산을 줄이고 질문 사이에 학생 사실을 캐시하지 않는다.
실제 사용자 평가를 자동 테스트로 가장하지 않으며 개발원 UAT 생략 결정은 유지한다.

지원 범위 밖 질문과 미확정 관계에는 답을 추측하지 않는다. 이 결정은 자유 대화의 무제한
정확성이나 최종 졸업 판정을 보증하지 않는다. [사용법](../../operations/conversation-prototype.md),
[계약](../contracts.md)을 참고한다.
