# ADR0021 — 실제 Gemma 문장 생성과 검증 경계

- 날짜:2026-10-01
- 상태:채택
- 범위:2026학번 컴퓨터공학과 초기 프로토타입. 학사 사실·승인은 변경하지 않음.

## 결정

기존 모델은 질문 의도 제안만 했다. 사용자 요청에 따라 실제 승인 근거 안내문을 생성한다.
단일 앱 안에 작은 공용 주장 계획·검증기를 추가하고 새 런타임 서비스나 에이전트 팀은 만들지
않는다. 하네스는 개발 과정에서만 사용한다. 학생 질문·성적표·부족 학점은 모델에 보내지 않는다.

기존 answer/EvidencePacket/계산을 불변으로 유지하고 명시적 opt-in에만 generated_answer,
generation_status, generated_claim_ids를 추가한다. 기본 요청·CLI·성적표 계약은 유지한다.
과거의 닫힌 응답 스키마는 opt-in 전에 갱신해야 한다. 새 출력도 서버와 소비자에서 검증한다.

모델이 실제 작성한 안내 문장을 검사한다. 단순히 숫자·ID가 같다는 것으로 자유 문장의
정확성을 인증하지 않는다. 학점 최소값은 닫힌 조합 문법, 다른 정책은 전체 승인 문장과 제한된
비학사 안내 접두어만 허용한다. 조건·예외·none_listed 한계를 생략하거나 추가 주장·부정·
충족 단정을 넣으면 전체 생성 결과를 거절한다. 인용은 모델이 만들지 않고 기존 코어에 연결한다.

공용 검증 문장만 제한적으로 캐시하며 generated/cached를 구분한다. 단일 공용 추론 예산,
공개 최소60초 간격, 최대512토큰·30초 대기·60초 실패 대기를 유지한다. 시간 초과가 서버측
취소를 뜻하지 않는다. 점유·실패 시 결정적 답변으로 돌아간다.

## 결과와 한계

질문 중심 화면과 단일[시작/종료 안내](../../operations/minimal-prototype.md)를 제공한다.
현재 검증은 문법으로 표현한 승인 주장에 한정하며 자유 대화·전체 학사 진실·최종 졸업 판정에
대한 보장이 아니다. 학생 이수 계산은 모델이 하지 않는다. 원문과 감사 이력은 보존한다.
