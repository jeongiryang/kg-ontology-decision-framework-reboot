# ADR 0009: 세션 범위 사용자 질문형 학사 검수

- 상태: 채택
- 날짜: 2026-09-18

## 맥락

프로젝트 소유자가 JSON과 스키마를 직접 검토하지 않고도 학사 규칙의 관계와 해석을 확인할
수 있어야 한다. 일반 대화의 발언을 학과 확인으로 오인하거나, 하위 운영 관행으로 상위 규정
충돌을 덮어쓰면 환각 방지 목표를 훼손한다.

## 결정

읽기 전용 `academic_review_facilitator`가 `AcademicClarificationPacket`을 제안한다. 메인
오케스트레이터만 사용자에게 질문하며, 세션 시작 시 한 번 받은 명시적 권한을 같은 task와
run의 후속 명시적 답변에만 적용한다. 한 배치는 최대 3개 질문, 질문은 2~3개 상호 배타적
선택지와 권장안·영향·차단 범위를 가진다. 모델러는 유효한 권한 사건과 정확한 응답이 연결된
대상만 반영한다. 질문 시점의 검수대장·SourceEntry·RuleFact 해시도 함께 고정한다. 미응답·모호한 답변·보류는 부분적으로 실패 폐쇄하고, 상위 규정 충돌은
공식 상위 또는 동급 근거가 생길 때까지 보존한다. 충돌 양측은 RuleFact의 단일 정규화 판정문이
아니라 각 근거의 원문 발췌와 위치에 결합한다. 닫힌 세션의 권한 종료 경로는 `거절`,
`부여→만료`, `부여→철회` 중 정확히 하나만 허용한다.
보존된 충돌을 다루는 질문에는 승인 선택지를 두지 않고 `accepted` 상태로 전환하지 않는다.
원문 주장은 유니코드·공백·문장부호와 숫자 뒤 `학점` 표기를 정규화한 뒤에도 달라야 한다.

## 결과

- 사용자는 스키마 대신 근거가 붙은 질문 화면만 검토한다.
- 세션 밖 발언과 침묵은 승인으로 승격되지 않는다.
- 독립 규칙 검수는 다른 질문의 보류와 무관하게 계속할 수 있다.
- 계약·의미 검증·CI·공개 보고서의 유지 비용이 늘지만 승인 경계가 재현 가능해진다.
