# ADR-0003: 원문과 민감정보를 공개 Git에서 제외한다

- 상태: 채택
- 날짜: 2026-09-17

## 맥락

학칙·교육과정 원문 PDF/HWP/XLSX는 배포 권리와 버전 관리 문제가 있고, 학생 성적표와 DSW 접속정보는 개인정보·보안 위험이 있다. 공개 저장소에 원문이나 로컬 경로를 넣을 필요 없이 무결성과 적용 범위를 추적할 수 있어야 한다.

## 결정

원문 PDF/HWP/XLSX, 학생 데이터, SSH 주소·계정, `.env`, `.local/`, 모델·체크포인트와 원시 실행 로그를 Git에서 제외한다. 공개 저장소에는 문서 식별자, 원본 출처, SHA-256, 시행일, 적용 학년도·학과, 권위와 검토 상태만 기록한다. 발췌본과 가공 XLSX는 단독 근거로 사용하지 않는다.

## 결과

저장소 공개 위험과 대용량 이력을 줄이면서 문서 버전을 검증할 수 있다. 신규 참여자는 원문을 별도 승인 경로로 받아야 하며, 해시만으로 내용 자체를 복원할 수는 없다. 공개 보고서는 비밀정보·학생정보·로컬 절대 경로 정제를 통과해야 한다.

## 검토한 대안

- 원문 전체 커밋: 권리·개인정보·저장소 크기 문제로 채택하지 않았다.
- 원문 정보 미기록: 재현성과 적용 문서 확인이 불가능해 채택하지 않았다.
