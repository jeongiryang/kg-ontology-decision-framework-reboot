# ADR 0014: 정확한 그래프 미러·인용 정정 계보·저부하 모델

상태: 채택. 기존 ADR 0012의 비권위 LLM 경계와 0013의 원문 비보존을 유지한다.

## 결정

- Registry가 의도·규칙·판정·계산을 선택한다. 선택적 Neo4j는 매 지원 답변마다 작은 전체 그래프를 제한된 읽기 트랜잭션으로 재구성하여 현재 승인 Registry와 정확히 대조한 후 기존 순서의 근거만 반환한다. 누락·추가·중복·속성·해시·원문 위치가 다르면 503 또는 CLI 종료 3이다. 활성 그래프 오류를 로컬 답변으로 숨기지 않는다.
- 그래프의 `answer_eligible` 표지는 코어의 승인된 좁은 정책 질문을 재판정하는 필터가 아니다. `record_only` 면제 가능성은 일반 정책 설명과 개인 자동 면제를 구별한다.
- 빈 DB 적재기는 명시된 전용 DB의 고유 `AcademicKG.node_id` 제약을 확인한 후 단일 트랜잭션으로 CREATE한다. 기존 DB를 동기화·삭제하지 않는다. 동일 코호트 키를 두 적재가 동시에 만들 수 없어 한 적재만 커밋한다. 결과가 불확실하면 전용 DB를 먼저 조회하고 임의 재적재하지 않는다.
- 원문 위치가 객관적으로 틀린 경우에만 `knowledge/evidence-corrections.json`에 이전/현재 규칙 전체 해시와 기존 locator/excerpt를 남긴다. 검증기는 오직 그 두 필드를 역복원해 원래 전체 해시가 재현되는지 확인한다. 결정·적용 범위·근거 출처·사람 승인을 바꾸는 통로가 아니다. 폐쇄된 검수 세션을 다시 쓰지 않는다.
- 선택적 LLM은 프로세스 전체 동시 1건·대기열 없음·기본 요청 간격 5초·실패 후 60초 냉각·32개/5분 주제코드 캐시·최대 64 출력 토큰이다. 모델은 학생 질문 원문을 받지 않고 답변 상태·인용을 생성하지 않는다. 단일 API 프로세스가 전제이며 여러 프로세스/앱의 공유 모델 전체 부하를 보장하는 분산 제어는 아니다.

## 검증 구분

참고 JSON의 교수님 챗봇 평가 요약, 새 합성 회귀, 실제 사람 UAT, 실 모델 추론은 별개다. 입력이 동일한 비식별 코드로 압축되면 모델은 구별할 수 없으므로 추측한 정확도나 원문 재현을 주장하지 않는다.

이번 실행의 추가 워커 생성은 세션 한도에서 실제 ID 없이 실패했다. 메인이 구현하고 기존 읽기 전용 역할을 재사용해 독립 리뷰·실행 검증했다. 시작하지 않은 네이티브 워커를 완료했다고 기록하지 않는다. 사전 GPU/디스크 검사만으로 모델 실행 성공을 기록하지 않는다.

## 결과

현재 규모에서는 전체 대조 비용을 허용한다. 데이터 증가 시 별도 버전 스냅샷·조회 계약을 재설계한다. 인증 없는 단기 전용 테스트 DB는 localhost 시험 범위이며 상시 운영에서는 전용 인증·권한·운영 승인이 필요하다.
