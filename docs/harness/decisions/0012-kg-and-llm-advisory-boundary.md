# ADR 0012: 승인 근거 그래프와 비권위 LLM 제안의 경계

## 상태

채택

## 배경

현재 초기 프로토타입은 승인된 2026학번 컴퓨터공학과 규칙으로만 답한다. 기존 Season 1에는
Ollama/OpenAI 호환 모델 어댑터와 Neo4j 적재 방식이 있지만 과거 발췌 PDF 기반 그래프를
새 교육과정에 그대로 사용할 수 없다. 다른 프로젝트의 과거 교수님 컴퓨터 모델 사용
기록은 확인됐지만 학사 프로젝트의 현재 직접 연결은 검증되지 않았다.

## 결정

- 승인 Registry를 해시·출처 위치가 포함된 로컬 그래프 번들로 결정적으로 투영한다.
  미검증 학과 운영 후보는 답변 가능 그래프에서 제외한다.
- 실제 Neo4j 적재는 명시적 전용 빈 DB, 접속 설정과 확인 플래그가 있을 때만 허용한다.
  기본 경로는 Git에서 제외된 로컬 번들 생성이다.
- 선택적 로컬 LLM은 결정적 엔진이 의도를 찾지 못한 안전한 질문의 **의도 ID 후보**만 제안한다.
  학생 대상 사실 문장, 답변 상태, 계산, 적용 규칙과 인용은 변경할 수 없다.
- 보호된 운영요건, 범위 밖, 충돌과 이미 근거가 연결된 질문은 모델에 보내지 않는다.
  모델 장애나 잘못된 출력은 기존 결정적 답변을 유지한다.
- 사용자 질문 원문과 학생 식별정보는 모델에 보내지 않는다. 정해진 비식별 주제 코드와
  승인 의도 ID만 전달하며 입력이 불확실하면 모델 호출을 생략한다.
- 모델 접속은 명시적 루프백 설정으로만 활성화하며 기본값은 꺼짐이다. 외부망 배포와
  교수님 컴퓨터 접속은 이 결정에 포함되지 않는다.

## 결과

그래프 구조와 LLM 연결 계약을 실제 학생 질문에 노출하기 전에 검증할 수 있다. 모델이 질문을
잘못 분류해도 승인되지 않은 학사 판정으로 승격되지 않는다. 실제 Neo4j와 교수님 모델의
성능·연결·학사 정확도는 아직 검증되지 않았으므로 별도 운영 승인 및 평가가 필요하다.
