# ADR0020: 사용자 PC의 익명 외부 HTTPS 시연

- 날짜: 2026-10-01
- 상태: 채택
- 범위: 사용자 PC의 임시 교수님 시연. 학사 승인·DSW 정책 변경 없음.

## 맥락과 사용자 결정

사용자는 같은 망이 아닌 외부에서 링크로 접속하고, 로그인 없이 자신의 성적표를 사용할 것을 명시적으로 요청했다. 기존 localhost 실행이나 사설망 가입은 이 요구를 충족하지 못한다. 인증 요구와 합성 자료만 허용하는 대안은 선택하지 않았다.

## 결정

Cloudflare Quick Tunnel로 별도 loopback 시연 앱만 HTTPS 중계한다. 계정·고정 도메인·공유기 포트 전달·외부 IP 바인딩·연구실 서비스 공개·OS 자동 실행은 추가하지 않는다. 기존 비공개 실행의 기본값은 유지한다.

`PublicDemo` ASGI 경계는 필요한 경로만 허용하며 본문·응답·전체 시간·동시 작업·전역 요청 예산을 제한한다. 문서·피드백 저장·관리 경로는 막는다. 공개 PDF 처리에는 소유 자식 프로세스의 시간·메모리 한도를 적용한다. 각 브라우저는 자신의 일시적인 이수내역만 다루고 취소·세대 번호로 오래된 응답을 배제한다. LLM은 이미 승인된 비권위 주제 제안 역할이며 공개 최소 간격을 60초로 높인다.

실행 파일은 공식 릴리스의 버전·SHA-256을 고정한다. 실행 관리자는 자기 자식만 추적하고 종료 시 중계부터 닫는다. 다른 프로세스·점유 포트·나루·DB를 종료하지 않는다. 프로그램은 사용자가 종료할 때까지 실행되지만 무한 재시작·원격 서비스 복구는 하지 않는다.

## 결과와 제한

주소 보유자는 누구나 접속할 수 있다. 학생 파일을 Git에 올리거나 기본 예제로 공유하지 않으며, 원본·과목·질문을 앱 로그에 보존하지 않는다. HTTPS 트래픽은 Cloudflare를 거친다는 사실을 화면·문서에서 알린다. PC·프로그램·근거 연결이 필요하고 다시 시작하면 URL이 달라질 수 있다. 임시 서비스의 가동 보장·대규모 부하·최종 졸업 인증은 포함하지 않는다.

## 검증

필수 경로와 거절 경로, 전체 수신 시간, 처리 제한·실패 정리, 전역 예산, 브라우저 취소/탭 분리, 실제 HTTPS 질문·인용·가상 성적표 및 종료를 확인한다. 별도 로그인 테스트는 선택한 요구가 아니다. 실행 방법은 [외부 시연 안내](../../operations/public-demo.md)에 둔다.
