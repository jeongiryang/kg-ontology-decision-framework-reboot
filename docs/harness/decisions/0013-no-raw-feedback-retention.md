# ADR 0013: 동의한 피드백에도 질문 원문을 보존하지 않는다

## 상태

채택. [ADR 0011](0011-opt-in-local-feedback.md)의 원문 저장 결정만 대체한다.

## 배경

비지원 질문의 원문을 동의 후 로컬에 저장하던 방식은 이름 검출 정규식에 의존했다.
독립 리뷰에서 정상 동사를 이름으로 오인하는 사례와 실제 이름을 놓치는 사례가 동시에
확인됐다. 모든 자유형 한국어·영문 성명을 안정적으로 식별한다고 보장할 수 없다.

## 결정

- 일반 답변은 계속 비저장이다. 피드백 API도 명시적 동의와 현재 답변 재검증을 요구한다.
- 새 로컬 피드백 기록 `2.0.0`에는 질문 원문을 남기지 않는다. 응답 ID, 상태, 보완 유형,
  고정 적용 범위와 시각만 보존한다.
- 명백한 식별정보는 입력 경계에서 계속 거절한다. 하지만 이름 탐지의 완전성을
  피드백 비식별화의 유일한 보호 수단으로 간주하지 않는다.
- 기존 `1.0.0` 기록은 집계 읽기 호환성만 제공한다. 당시의 명시적 식별자 검사로
  별도 검증하되, 이후 더 엄격해진 자유형 이름 휴리스틱을 소급 적용해 정상 기록 전체를
  읽을 수 없게 만들지 않는다. 원문을 새 파일로 자동 이전하거나 공개하지 않는다.
  실제 학생정보가 발견되면 운영자가 별도 삭제 절차를 따른다.

## 결과

응답별 상태·유형과 중복 건수는 분석할 수 있지만, 저장 기록만으로는 실제 질문 문장을
복원할 수 없다. 구체적인 실패 질문을 평가셋에 넣으려면 별도 비식별 수집과 사람 검수가
필요하다. 이 손실은 개인정보 오보존 위험을 줄이기 위해 허용한다.
