# 내부 시험운영 가이드

## 현재 허용 범위

이 단계는 한 대의 관리 PC에서 `127.0.0.1`로 실행하는 비공개 시험운영이다. 지원 범위는
2026학번·2026 교육과정·컴퓨터공학과이며, 공모전·캡스톤·졸업작품·PCCP는 공식 근거가
확보될 때까지 `insufficient_evidence`로 유지한다.

실제 학생정보, 원본 성적표, 이름, 학번과 연락처를 입력하지 않는다. 사용성 평가에는 비식별
질문과 학점 합계만 사용한다. 피드백은 사용자가 동의 확인란과 저장 버튼을 직접 누른 경우에만
Git에서 제외된 로컬 JSONL에 기록된다.

## 시작 전 점검

Python 3.12 가상환경에서 설치와 읽기 전용 준비 검사를 실행한다.

```bash
python -m pip install -e ".[test]"
python scripts/operations/check_pilot_readiness.py --project .
```

모든 항목이 `PASS`이고 마지막 줄이 `READY`일 때만 시작한다. 검사는 레지스트리 무결성,
승인 답변의 근거 연결, 보류 주제의 실패 폐쇄, 피드백 경로의 Git 제외를 확인하며 질문을
저장하지 않는다.

## 시작과 종료

```bash
uvicorn academic_assistant.api:app --host 127.0.0.1 --port 8000
```

브라우저에서 `http://127.0.0.1:8000/`과 `http://127.0.0.1:8000/readyz`를 확인한다.
종료할 때는 실행 터미널에서 `Ctrl+C`를 누르고 프로세스가 끝났는지 확인한다. 디버그 모드,
자동 재시작과 장기 상주는 사용하지 않는다.

## 피드백 검토와 보존

기본 피드백 경로는 `.local/academic-feedback/feedback.jsonl`이다. 원본은 공개 저장소,
GitHub Issue, 완료 보고서에 복사하지 않는다. 검토 도구의 기본 요약은 질문 원문을 출력하지
않으며 상태·분류·중복 건수만 확인한다. 실제 질문을 평가셋으로 옮길 때는 개인정보를 다시
검사하고 사람이 의미와 기대 상태를 승인한 별도 PR로 추가한다.

저장 경로를 바꿀 때는 `ACADEMIC_FEEDBACK_PRIVATE_ROOT`와 그 하위의
`ACADEMIC_FEEDBACK_PATH`를 함께 설정한다. 저장 함수가 승인된 private root 밖의 경로를
거절하므로 공개 저장소 루트나 다른 작업트리를 목적지로 사용하지 않는다. 현재 내부 파일럿의
준비 검사는 프로젝트 `.local` 하위만 허용한다. 외부 private root는 별도 운영 검토 전까지
사용하지 않는다.

```bash
academic-assistant feedback-summary --json
```

피드백 보존 기간과 폐기 담당자가 정해지기 전에는 외부 공유나 자동 업로드를 하지 않는다.
오입력이나 개인정보가 발견되면 서비스를 중지하고 로컬 파일의 정확한 위치와 영향 범위를
확인한 뒤 프로젝트 책임자가 정한 절차로 삭제한다.

## 연구실 서버와 내부망 공개 경계

이 문서는 DSW 배포 승인이 아니다. 현재 단계에는 SSH 접속, GPU 사용, 상주 서비스 실행,
방화벽 변경과 내부망 공개가 포함되지 않는다. DSW에서 실행하려면 먼저 접속 정보와 망/VPN,
운영 담당자, 접근 인증, 보존 기간, 상주 서비스 승인 참조를 확정해야 한다. 실행 전에는
`whoami`, `uptime`, `nvidia-smi`, `df -h`를 확인하고 기존 DSW 운영 계약을 따른다.

다른 PC에서 접속하도록 `0.0.0.0`에 바인딩하는 것은 별도 보안 설계와 승인 전까지 금지한다.
승인 뒤에도 TLS 종료, 인증, 요청 제한, 감사·삭제 정책을 먼저 마련해야 한다.

## 장애와 롤백

- `/readyz`가 200이 아니면 질문 서비스를 열지 않는다.
- 승인 규칙 해시나 출처 검증이 실패하면 서비스는 실패 폐쇄 상태로 둔다.
- 피드백 쓰기가 실패하면 답변 기능과 분리해 503을 반환하며 임의 경로로 우회 저장하지 않는다.
- 새 버전 회귀가 발생하면 프로세스를 종료하고 마지막으로 CI가 성공한 커밋에서 다시 설치한다.
- 사고 기록에는 학생정보, 서버 주소, 계정과 로컬 절대 경로를 넣지 않는다.
