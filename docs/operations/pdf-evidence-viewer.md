# 답변 근거 PDF 표시

학사 답변과 성적표 비교의 **근거 PDF 보기** 버튼으로 인용한 원본 페이지를 확인한다.
원본 PDF는 수정하지 않는다. 빨간 밑줄이 들어간 이미지와 다운로드용 한 페이지 PDF는
메모리에서 만든 표시용 사본이며 저장소나 학생 기록에 저장하지 않는다.

## 정확한 위치와 페이지 보기의 구분

- `exact`: 승인된 인용문이 원문에서 유일하게 일치하거나, 승인된 출처 해시·학과·입학년도·표의 열·값이 모두 일치한 위치만 표시한다.
- `page_only`: 수기 확인서, 병합 표, 중복 문구처럼 정확한 위치를 확인할 수 없으면 빨간 줄 없이 승인된 인용 페이지만 보여주고 이유를 알린다.

숫자만 검색해서 같은 숫자에 줄을 긋지 않는다. 교육과정의 졸업학점 표는
컴퓨터공 행,2026입학년도,해당 학점 열을 함께 표시한다. 아직 확인되지 않은 프로그램
행이나 대체·예외 관계를 위치 표시 기능이 승인하는 일은 없다.

## 비공개 원본 등록

`ACADEMIC_SOURCE_MAP`에는 승인된 `source_id`를 원본 PDF의 절대 위치로 연결한
비공개 JSON 파일을 지정한다. 이 파일과 원본은 Git에 넣지 않는다. 등록된 출처 ID 이외의
파일은 열 수 없다. 매 요청마다 PDF SHA-256을 승인된 SourceEntry와 비교한다.
파일이 없거나 해시가 다르면503,등록되지 않은 규칙이나 인용 페이지는404다.

```json
{"approved.source.id": "<private-original-pdf-location>"}
```

성적표 파일은 이 원본 등록의 대상이 아니다. 사용자 PDF를 학사 규정의 근거로 공개하지 않는다.

## API

- `GET /v1/academic/evidence/{rule_id}/preview`: 검증된 출처·해시·PDF/인쇄 페이지·인용문·정밀도·표시 URL.
- `GET /v1/academic/evidence/{rule_id}/preview.png`: 표시용 페이지 이미지.
- `GET /v1/academic/evidence/{rule_id}/preview.pdf`: 동일 페이지의 표시용 PDF 사본.
- `evidence_index`: 규칙의 승인된 근거 배열에서0부터 시작하는 번호.
- `pdf_page`: 원문 PDF의1부터 시작하는 페이지. 해당 규칙이 인용한 페이지 외에는 거절한다.

이미지와 PDF는 동일한 원본 해시·인용 선택을 다시 검증한다. 원본 전체 다운로드나
임의 파일 경로 입력은 제공하지 않는다. 정확한 위치 검증 실패와 출처 검증 실패는 다르다.
전자는 `page_only`,후자는503으로 처리한다.

## 실행과 연결 상태

Git에서 제외된 `.local/prototype.json`에 허용된 서비스 환경 변수만 넣고 실행한다.

```bash
python scripts/operations/start_prototype.py --config .local/prototype.json
```

주소와 포트는 localhost8000,단일 프로세스로 고정된다. `/v1/academic/runtime`은
활성 Neo4j 근거 검증과 LLM 모델 목록을 읽어 상태를 표시한다. 이 읽기 전용 준비 검사는
모델을 적재하거나 추론을 실행하지 않으며,성능·답변 정확도 검증을 대신하지 않는다.
LLM은 현재 비식별 주제 코드의 질문 표현 후보만 제안하고 학사 판정을 생성하지 않는다.
