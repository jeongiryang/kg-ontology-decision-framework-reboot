# B v2 추가 수정 창 — 총4회 이내

이번 실행은 기본2회 이후의 실제 실패를 보존한 유한 예외다.
기존 [B v2 계약](b-dialogue-v2.md)과 [ADR0027](../harness/decisions/0027-prototype-dialogue-repair-and-observed-progress.md)의
3회 호출·30초·8KiB·개인정보 비저장·A 비전송·2026컴퓨터공학과 범위는 유지한다.
회차3·4 이후 필수 실패를 숨기거나 별도 질문을 수정용으로 재분류하지 않는다.

## 확인된 결함과 완료 기준

- 실제 Gemma 조회 계획은2048문맥 중2014입력+34출력에서 `length`로 잘렸다.
  요청별 문맥 최대8192를 명시하고 실제 완결성/종료 사유를 검사한다.
  복합 요청도 완전한 조회 명세를 유지하며 무제한 생성이나 추가 서비스는 금지한다.
- 모델의 진행 설명에 학사 숫자·등급·의무·관계 등 답변 주장을 넣지 않는다.
  단어형 숫자, 추측형 술어, 복합 문장도 검증하고 안전한 작업 설명만 표시한다.
- 선행조건 검증은 화제 주어/상대절/수강 대상에 연결한다. 옳은 역순 어순은
  허용하되 실제 방향 반전·부정·개인 졸업 보장은 거절한다.
- 명시적인 타 학과 학생/전공 문맥은 짧은 이름·알려지지 않은 학과도CS요건으로
  답하지 않는다. 일반 명사의 접속조사 ‘과’만으로 범위를 차단하지 않는다.
- 질문 예문을 외우는 목록을 추가하지 않는다. 동결된 새 질문의 별도14건은
  구현 담당에게 공개하지 않으며 QA 기대값은 승인 자료에서 독립적으로 정한다.

## 기록

회차1·2 실패, 독립 리뷰, 실제 모델 응답과 수정 회차는 로컬 실행 장부에 보존한다.
공개 보고는 합성 질문·정제된 오류·검사·변경만 포함하고 실행하지 않은 검사는
`not_run`으로 둔다. 필수 검사와 실제 평가를 통과하기 전 완료나 새 시연 배포를 주장하지 않는다.
