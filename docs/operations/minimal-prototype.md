# 최소 학사조교 프로토타입

## 사용자 실행

프로젝트 PowerShell에서 아래 한 가지 진입점만 사용한다. 이미 실행 중이면 중복 시작하지
않고 현재 주소를 보여 준다. 초기 연결은 Git에서 제외된 설정과 기존 DB·모델 연결을 사용한다.

```powershell
.\demo.ps1 start
.\demo.ps1 status
.\demo.ps1 stop
```

출력되는 임시 HTTPS 주소를 교수님께 전달한다. 로그인은 없고 다른 네트워크에서도 접근할
수 있다. PC·인터넷·근거 DB 연결을 유지해야 하며 재시작하면 주소가 바뀔 수 있다.
운영 서버나 고정 주소는 아니다. [공개 시연의 범위](public-demo.md)를 따른다.

## 화면에서 할 일

1. 질문을 입력한다. 지원 범위는2026학번 컴퓨터공학과다.
2. 답변과 출처를 확인한다. `근거 PDF 보기`에서 검증된 위치의 빨간 밑줄을 볼 수 있다.
   학과 확인 기록은 PDF와 구분하며 PDF를 꾸며 만들지 않는다.
3. 개인 비교는 아래`성적표로 남은 학점·필수과목 확인`을 펼친다. PDF 인식 결과를
   직접 수정·확인한 뒤 부족 학점과 필수과목을 비교한다. 가상 예제도 제공한다.

적용 규칙 해시 등 기술 상세는 접어 두었다. 공개 시연에서는 피드백 수집을 숨기고
원문·자료를 저장하지 않는다. 개발원 직접 UAT는 요청에 따라 생략한다.

## 실제 동작 구조

```text
브라우저 → 단일 FastAPI 앱 → 승인 규칙·Neo4j 근거 검증 → 결정적 판정·계산
                                └→ Gemma 안내문 작성 → 닫힌 문법 검증
출처 버튼 → 원본 PDF의 검증된 인용 페이지·밑줄
성적표 → 호스팅 PC에서 인식·확인·계산 (모델 전송 없음)
```

추가 벡터DB·에이전트 상주 서비스·LLM 프레임워크는 없다. 하네스와 에이전트는 개발·검증
도구이며 사용자의 질문마다 실행되지 않는다. 기존 역사 문서·감사 기록은 삭제하지 않는다.

## Gemma의 역할과 한계

실제 연구실의 기존 Gemma 서비스를 나루와 다른 GPU0에서 사용한다. 모델은 **안내 문장**을
작성하고, 졸업 판정·학점 계산·적용 규칙·인용은 결정적 코어가 맡는다. 자유로운 학사 판정이나
무제한 자연어 해석 기능은 아니다. 등록되지 않은 질문은 추측하지 않는다.

생성 요청에는 승인된 공용 규칙 문장·해시·범위만 보낸다. 학점 기준은 최소값·대상을 보존하는
제한된 한국어 문법을 검사하고, 다른 정책은 조건·예외를 포함한 원문 규칙 문장 전체를
보존하도록 검사한다. 최대5개 주장·1,800자까지이며 더 큰 답변은 기존 안내를 쓴다.
모델이 쓴 실제 문장만 통과 후 표시하고 새 주장·조건 삭제·수치 변경은 거절한다.

검증 성공은`Gemma 작성 · 근거 문장 검증 통과`, 재사용은`Gemma 작성 · 검증된 문장 재사용`으로
구분한다. 모델 목록이 보인다는 사실만으로 추론 성공을 표시하지 않는다. 실패·시간 제한·
공유 예산 점유 시 기존 답변을 표시하며 상태·계산·근거를 바꾸지 않는다.

Ollama의 공식 API가 지원하는 JSON Schema 출력과 비사고·비스트리밍 요청을 사용한다.
JSON 형식 준수만으로 의미가 맞는 것은 아니므로 문장 검증을 별도로 수행한다.
[Ollama generate API](https://docs.ollama.com/api/generate),
[구조화 출력](https://docs.ollama.com/capabilities/structured-outputs).

동시 모델 요청은1개, 공개 모드의 서로 다른 새 요청 간격은 최소60초, 출력은 최대512토큰,
새 문장 생성은Ollama의 숫자 loopback HTTP 연결만 지원한다. 기존 의도 제안 연결은 유지한다.
연결·전송·응답 헤더·본문 전체에 걸친 단조시계 기한은 최대30초다. 느린 조각 응답도
기한을 연장하지 않으며 자기 소켓만 닫는다. 응답 헤더는8KiB, 본문은 설정된 크기로 제한하고
리다이렉트·모호한 프레이밍을 거절한다. 모델·규칙 해시에 묶인 검증 문장만 최대5분·32건 캐시한다.
수신 시간 초과가 원격 추론 중단을 보증하지 않으며 실패 후 최소60초 대기한다.
나루 프로세스·GPU는 변경하지 않지만 공유 CPU·전력 등에 대한 완전한 무영향은 보증하지 않는다.

기존3개 보류(심화 인정 과목 범위, 면제자의 수강·학점 처리, 정확한 PCCP 제출 학기)는
그대로다. 실제 학생 정보나 성적표는 모델에 보내지 않으며 최종 졸업 인증을 대신하지 않는다.
