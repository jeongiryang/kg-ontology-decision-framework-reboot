# 외부 링크로 교수님께 시연하기

같은 와이파이가 아니어도, 사용자 PC에서 실행 중인 웹을 **로그인 없는 HTTPS 링크**로 열 수 있다. 사용자는 자신의 성적표 사용과 익명 링크 접속을 명시적으로 승인했다. 이는 외부 운영 서비스가 아닌 임시 시연 모드다.

## 시작·주소 확인·종료

기존 비공개 Neo4j·연구실 모델 연결과 `.local/prototype.json`이 준비된 상태에서 프로젝트 PowerShell에서 실행한다.

```powershell
./scripts/operations/public_demo.ps1 -Background
./scripts/operations/public_demo.ps1 -Status
./scripts/operations/public_demo.ps1 -Stop
```

첫 명령은 숨겨진 시연 실행을 시작한다. 상태 확인에 나온 `https://…trycloudflare.com` 주소를 교수님께 전달하면 된다. 일반 실행은 `-Background` 없이 사용하고 Ctrl+C로 종료한다. 상태와 주소는 Git에서 제외된 `.local/public-demo-state.json`에만 저장한다. 주소를 GitHub에 자동 게시하지 않는다.

시작 준비 중 종료를 요청해도 이전 실행이 아니라 현재 실행을 대상으로 한다. 실행 신원을 게시하는 짧은 구간에서는 종료 요청을 명시적으로 재시도하며, PowerShell 도구는 최대 10회만 재시도한다. 종료 실패를 성공으로 표시하거나 다른 프로그램을 종료하지 않는다. 근거 DB 준비 확인은 회당 최대 3초, 전체 시작은 최대 90초다.

PC가 켜져 있고 인터넷에 연결되어 있으며, 시연 프로그램·근거 DB 연결이 유지되어야 한다. 절전·재부팅·프로그램 종료 시 링크도 끊긴다. 프로그램을 다시 실행하면 주소가 바뀔 수 있다. PC 절전·방화벽·공유기·부팅 자동 실행 설정은 자동 변경하지 않는다.

Windows 공개 웹 자식은 기본 Python 런타임의 자동 추가 패키지를 불러오지 않고, 프로젝트 소스와 프로젝트 가상환경의 명시된 의존성만 사용한다. 다른 작업용 분석 라이브러리의 자동 로딩을 방지하며, 시스템 설치나 기존 비공개 실행은 변경하지 않는다.

필요한 실행 파일은 공식 Cloudflare `cloudflared` Windows amd64 **2026.9.3**이다. `.local/tools/cloudflared-2026.9.3.exe`에 두며, 시작할 때 SHA-256 `f096265ec2fcbe9bb6e2d64268db167ced3fcbb83d894bdb9e2fcdb26f2ea7e2`가 일치해야 한다. 다른 파일을 실행하거나 자동 다운로드·갱신하지 않는다. 버전 갱신은 공식 릴리스와 체크섬을 확인하고 별도 검수한다.

## 무엇이 열리는가

웹 화면, 학사 질문, 이수내역 비교, PDF 과목 인식과 승인된 인용 페이지 표시만 허용한다. `/docs`, `/redoc`, `/openapi.json`, 피드백 저장, 임의 파일·DB·모델·관리 경로는 닫는다. 별도 시연 앱은 `127.0.0.1:8765`에만 바인딩한다. 기존 `127.0.0.1:8000`과 연구실 LLM·Neo4j·SSH 포트를 외부에 직접 열지 않는다.

로그인은 없다. **주소를 아는 누구나 사용할 수 있으므로 링크 전달 범위를 사용자가 관리한다.** 성적표는 각 방문자의 선택 파일·현재 요청으로 처리하며, 사용자 PC의 성적표를 기본 예제로 공개하지 않는다. 다른 브라우저·탭의 자료를 조회하는 공유 기능이나 서버 기록 보존 기능은 없다. 창을 닫거나 자료를 지우면 화면과 진행 중인 요청을 정리한다. 취소된 서버 작업도 정해진 시간 내 자신이 생성한 작업만 종료한다.

## 성적표와 중계 업체

방문자 ↔ Cloudflare HTTPS 중계 ↔ 사용자 PC 경로로 질문과 업로드가 전달된다. HTTPS라고 해서 중계 업체가 없는 직접 접속은 아니다. 성적표 인식·계산은 호스팅 PC에서 수행하며 GPU 모델에는 학생 질문 원문·성적표를 보내지 않는다. 질문·과목·원본 파일·방문자 IP는 이 시연 앱의 파일 로그에 저장하지 않는다. 중계 서비스의 처리 정책은 별도다. 공개 화면에도 이 흐름을 알린다.

## 자원 제한

| 항목 | 전역 제한 |
| --- | --- |
| 전체 요청 | 분당 120회, 동시 4개 |
| 학사·이수내역 POST | 분당 12회, 작업 동시 2개 |
| PDF 과목 인식 | 10 MiB 이하, 분당 2회, 동시 1개 |
| 원본 인용 미리보기 | 분당 12회, 동시 1개 |
| 모델 목록 확인 | 분당 6회, 추론 없음 |
| 요청 본문 수신 | 총 30초 |
| 답변 대기 | 총 150초; 늦은 작업이 끝날 때까지 해당 작업 슬롯 유지 |
| PDF 과목 인식 자식 | 120초, 공개 모드 768 MiB |
| PDF 인용 표시 자식 | 20초, 공개 모드 768 MiB |
| JSON 본문·응답 | 256 KiB·16 MiB |
| 모델 제안 | 공개 실행에서 최소 60초 간격 |

방문자 주소 헤더를 바꿔도 전역 예산을 늘릴 수 없다. 제한이면 429와 재시도 안내, 시간·근거 검증 실패이면 제한된 오류만 반환한다. 학생 자료가 오류에 포함되지 않는다. 이는 소규모 교수님 시연용이며 대규모 익명 서비스·무중단 운영·나루 무영향을 보증하지 않는다.

## 확인과 지원 범위

1. 상태 확인 후 공유 주소를 외부 브라우저에서 연다.
2. `졸업 총학점은?` 같은 승인 질문의 답변·적용 범위·근거를 확인한다.
3. 근거 PDF 보기를 열어 정확한 위치와 페이지 번호를 확인한다.
4. 가상 이수내역 또는 사용자가 허용한 성적표로 과목 인식 후 반드시 수정·확인하고 비교한다.
5. 작업 후 종료하고 공유 주소가 더 이상 연결되지 않는지 확인한다.

실제 학번 지원은 여전히 **2026학번 컴퓨터공학과**다. 심화 인정 과목 범위·면제자의 수강/학점·정확한 PCCP 제출 학기는 [보류 질문](../../reviews/academic/clarifications/20261001-prototype-followup-questions.md)으로 유지한다. 최종 졸업 인증은 아니다.

[Cloudflare 공식 Quick Tunnel 안내](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/)에 따르면 계정·도메인 없이 임시 주소를 만들 수 있으며, 주소 보유자가 접속할 수 있다. 가동 보장 없는 개발·시험용 기능이고 실행 종료 시 연결도 종료한다. 고정 주소·운영 서비스가 필요하면 별도 계정·도메인과 운영 정책을 결정한다.
