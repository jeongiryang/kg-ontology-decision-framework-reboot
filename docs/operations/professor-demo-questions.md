# 교수님 시연용 질문 예시

2026학번 컴퓨터공학과의 승인 근거만 사용한다. 아래10개는 시연의 순서이며 지원 메뉴나
질문 수 한도가 아니다. 전체31주제와 표현 변형·복합 질문을 별도로 평가한다.
PC·인터넷·모델/근거 연결을 켜고 `demo.ps1 start`의 임시 HTTPS 주소를 사용한다.

1. “졸업하려면 총 몇 학점을 이수해야 하나요?”
2. “교양을 모두 합쳐서 몇 학점 들어야 하나요?”
3. “전공필수 학점은 얼마나 이수해야 하나요?”
4. “전공필수로 어떤 과목을 들어야 하나요?”
5. “균형교양에서 몇 개 영역을 이수해야 하나요?”
6. “심층상담은 몇 번 해야 하나요?”
7. “졸업논문이0학점이어도 반드시 이수해야 하나요?”
8. “PCCP 합격 기준 점수는 몇 점인가요?”
9. 확인한 성적표가 있을 때: “내 성적표에서 남은 전공필수 과목은?”
10. 확인한 성적표가 있을 때: “내 성적표에서 졸업까지 몇 학점 더 필요해?”

## 대화와 근거 보여 주기

- 첫 질문 뒤 총 이수학점100을 선택 입력하고 기준을 다시 질문한 다음,
  “그럼 몇 학점 남았어?”라고 이어 묻는다. 부족30학점은 입력과 해당 기준의 비교이지
  졸업 가능 인증이 아니다. 입력 변경 시 이전 문맥은 지우므로 기준을 다시 지정한다.
- “전공필수와 전공선택 학점 기준을 설명해 주세요.”처럼 여러 기준을 묻는다.
  이어 “몇 학점 남았어?”라고만 말하면 하나의 비교 대상을 선택하도록 안내해야 한다.
- PDF 인용의 `근거 PDF 보기`에서 검증한 페이지와 빨간 밑줄을 확인한다.
  학과 확인 기록에는 PDF를 만들어 붙이지 않는다.
- 성적표 예제를 넣거나 PDF 인식 결과를 직접 수정한 뒤 확인한다. 일부 기록이나
  인정 근거가 부족한 항목은 `확인 필요`로 남으며 부족분을 확정하지 않는다.
- **새 대화**를 누른 뒤 앞 질문과 성적표가 사라지고, 맥락 없는 “그럼 얼마나 남아?”에는
  비교 대상을 다시 묻는 것을 확인한다.

## 한계도 함께 보여 주기

“간호학과 졸업학점 알려주세요”, “면제받으면 캡스톤 학점도 인정되나요?”,
“PCCP 제출의 정확한 학기는?”처럼 범위 밖 또는 보류인 질문은 근거 상태를 명시해야 한다.
PCCP400점은 승인된 시범 운영 기준이며 미래의 고정 기준이나 개인 면제 보증이 아니다.

Gemma 생성·검증 문장 재사용·모델 미사용 안내를 구분한다. 첫 안내는 모델을 기다리지
않고 표시하며 선택적 다듬기의 실패가 답변과 근거를 없애지 않는다.
학생 질문·성적표·개인 부족분을 모델에 보내지 않고 대화는 탭 메모리에만 둔다.
시연 예시는 실제 개발원 UAT 결과가 아니다. [사용법과 범위](conversation-prototype.md)를 참고한다.
